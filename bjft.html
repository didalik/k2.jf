Basic WebSocket Test

This WebSocket client runs in a browser. Two more clients run locally in Node JS. All clients share the same code and connect to CF DO WebSocket Server with Hibernate. Each client sends 3 messages to the server. The server broadcasts whatever a client sends it to all other clients and closes a client's connection having sent 6 messages to it.

Having sent the first message, a client waits long enough for the server side to hibernate on the connection. A client can still send a message after the server closes its connection - the server's ctx.getWebSockets() call returns clients with readyState == 2 (CLOSING).
